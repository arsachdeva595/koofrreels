Publer Integration

Connect Publer to push approved reels directly to your social media scheduler queue.

How to get your Publer API key

  1. Log in to app.publer.io
  2. Go to Settings → Access & Login → API Keys
  3. Click Generate New Key
  4. Copy the key and paste it in the API Keys tab above
  5. Find your Workspace ID in the URL: app.publer.io/workspaces/YOUR_ID
